# Archive — historical specs & plans (NOT current instructions)

**These files are frozen. Do not execute them as if they were live work.**

They are the per-phase design specs and implementation plans from Phases 1–4A, produced
under the old brainstorm → spec → detailed-plan process (superseded 2026-06-09). They are
kept for the historical "why" only. They were accurate when written and have NOT been
updated since; paths, file names, and decisions in them may be stale.

## Where current instructions live

| You want… | Read |
|---|---|
| What to build (product spec) | `PRD.md` |
| How work is sliced into agent sessions | `IMPLEMENTATION_PLAN.md` (session cards) |
| Rules, gotchas, live phase status | `CLAUDE.md` (canonical; `AGENTS.md` mirrors it) |
| Why a past decision was made | `docs/context-history.md` |

`docs/context-history.md` is the living "why" doc and links into these archived files where
a full write-up is useful. Cross-references *between* archived files (spec ↔ plan) still use
their original `docs/superpowers/...` paths and are not maintained — the directory is now
`docs/archive/`.

Nothing here should be treated as a TODO. Current work = `IMPLEMENTATION_PLAN.md` cards.
